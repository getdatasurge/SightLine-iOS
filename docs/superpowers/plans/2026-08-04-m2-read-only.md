# SightLine Field — M2 Read-Only Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Technician-scoped v1 read endpoints in the web repo + iOS delta sync so the skeleton's shells show real data, offline after first sync.

**Architecture:** Backend first (Tasks 1–6, web repo worktree, branch `integration/field-app`): new reads reuse module barrels, price-blind projection lives in the route adapter, every route lands with its OpenAPI entry and tests in the same commit. Then iOS (Tasks 7–12): regenerated client, a store-writing `SyncEngine` (snapshot + `updatedAfter` delta per collection), capability-aware UI, extended smoke test.

**Tech Stack:** Next.js v1 API (Zod, Prisma, vitest) · Swift/SwiftUI/SwiftData, swift-openapi-generator, XCTest.
